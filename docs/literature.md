## Per-paper summaries

### 1. Chang & Park, IEEE TIE 2019: 10.1109/TIE.2018.2835386
**Summary (abstract).** The authors combine time–frequency-domain reflectometry (TFDR) with deep learning to check that each wire is plugged into the correct port of a vehicle's underhood electrical center during assembly. They design an optimized reference signal for the frequency characteristics of four wire types (black, blue, red, yellow). The reflected signal is acquired with time–frequency cross-correlation (TFCC), converted into a Wigner–Ville distribution image, transformed so that groups separate, and classified by a CNN. A filter bank stores each wire's length, compensation filter and port. If the TFCC-derived distance differs from the stored length, the wire is flagged as defective, and the signal is restored with a compensation filter designed by an overcomplete wavelet transform. The abstract reports only that experiments "demonstrate the effectiveness"; it gives no numerical accuracy.
**Line type.** Automotive wiring harness wires, not coax.
**Use in project.** Cite in related work as an example of heavy deep-learning pipelines (time-frequency images + CNN), in contrast to our lightweight tree ensembles on raw or engineered TDR features. The "measured distance vs. stored healthy length" check is a useful idea for the conventional baseline (reference-subtraction/deviation test). It also supports the limitations discussion: results on automotive wires don't carry over to coax without retraining.
**Sources checked:** Crossref API `https://api.crossref.org/works/10.1109/TIE.2018.2835386` (bibliographic data, no abstract); Semantic Scholar API `.../paper/DOI:10.1109/TIE.2018.2835386` (abstract; open-access status CLOSED); OpenAlex API `https://api.openalex.org/works/https://doi.org/10.1109/TIE.2018.2835386` (abstract, identical). Full text not accessed.

### 2. Shin et al., IEEE TIM 2005: 10.1109/TIM.2005.858115
**Summary (abstract).** The paper introduces a high-resolution reflectometry technique, time-frequency domain reflectometry (TFDR), that works in the time and frequency domains at once. The reference signal is a linear chirp multiplied by a Gaussian time envelope: the envelope gives time localization, and the chirp sweeps a chosen frequency band. Detection sensitivity comes from a time-frequency cross-correlation function. The method was verified experimentally by locating various types of faults at various distances in **RG 142 and RG 400 coaxial cables**.
*(Full text, author-hosted copy.)* The experimental programme had 48 runs: 2 cable types × 3 fault types ("open", "short", and "damage", which was 1 cm of outer shield removed) × 4 distances (10, 20, 30, 40 m). Each was done with TFDR and repeated with a commercial TDR with 300 ps rise time. TFDR gave "somewhat better accuracy" in fault localization than TDR. The paper notes that TDR accuracy is limited by rise time and pulse distortion (dispersion/skin effect), and that multiple reflections complicate TDR.
**Use in project.** *Theory:* explains why rise time and dispersion limit TDR distance accuracy, which justifies the error sources in d = vp·Δt/2. *Baseline:* cross-correlation time-of-flight estimation is a natural "strong conventional" baseline next to threshold/peak detection. *Evaluation:* its cable × fault type × distance grid, with open/short classes on coax, is a ready template for designing our lab test set and comparing against a reference instrument.
**Sources checked:** Crossref API (bibliographic data, no abstract); Semantic Scholar API (abstract elided by publisher); OpenAlex API (abstract); doi.org → `https://ieeexplore.ieee.org/document/1542557/` (**IEEE Xplore returned HTTP 202 with an empty body; not accessible**); author-hosted PDF `http://www.ece.utah.edu/~cfurse/Center of Excellence/wiring_papers/Application_of_time_frequency_domain_reflectometry_..._dec2005.pdf` (abstract verified verbatim; experimental details above).

### 3. Smail et al., IEEE TMAG 2011: 10.1109/TMAG.2010.2089503
**Summary (abstract).** The paper presents a technique to reconstruct faulty wiring networks and/or localize defects on network branches from the TDR response, and also to characterize those defects. The forward model of wave propagation along the lines uses RLCG per-unit-length parameters, computed by the finite element method or analytically, with the finite-difference time-domain (FDTD) method. Neural networks solve the inverse problem, mapping the TDR response to network or defect parameters. The calculations are validated with experimental results. The abstract does not give quantitative accuracy, the specific cable type, or the network topology: **UNVERIFIED**.
**Venue note.** Crossref and HAL list it as IEEE Trans. Magnetics 47(5), 2011. Semantic Scholar lists it as the CEFC 2010 conference digest, where it was presented before TMAG publication. Cite the TMAG version.
**Use in project.** This is the closest methodological ancestor of our pipeline: a *physics-based simulator* (telegrapher equations with RLCG + FDTD) generates training data, and an ML model inverts it, followed by an experimental check. Cite it in the **simulation model** work package (RLCG/FDTD as an accepted forward model) and in **sim-to-real** as an early example of training on simulation and testing on measurements.
**Sources checked:** Crossref API (bibliographic data, no abstract); Semantic Scholar API (abstract elided; venue shown as CEFC 2010); OpenAlex API (abstract); HAL API `halId_s:hal-00710603` (abstract identical; **no full-text file on HAL: `/document` returned 404**); doi.org → `https://ieeexplore.ieee.org/document/5754769/` (**HTTP 202 with an empty body; not accessible**). Full text not accessed.

### 4. Slimani et al., IEEE AUTOTESTCON 2024: 10.1109/AUTOTESTCON47465.2024.10697515
**Summary (abstract).** The paper proposes fault diagnosis that combines machine learning with compressed acquisition of orthogonal multi-tone TDR (OMTDR). Learning and test sets come from a wired-diagnostic simulator. KNN and a CNN are applied directly to the compressed reflected signals without reconstruction, separately for impedance estimation and for localization. The paper compares the two models and studies how the compression factor affects localization.
*(Full text, HAL open-access copy.)* The setup is a simulated **RG58-CU coaxial cable, 10 m**, with Zc printed as 58 Ω, and a **single fault per cable**. Classes are short circuit, open circuit, soft fault (local resistive, Zi in [52.2, 63.8] Ω), and no fault. There are 9,900 positions at 1 mm steps per class, for **39,600 simulated signals**, with Gaussian noise at SNR 0–60 dB and an 80/10/10 split. The CNN regresses the **reflection coefficient Γ** through a tanh output, and fault type follows from Γ (−1 short, +1 open, |Γ| < 1 soft). Results at SNR 0–60 dB: CNN beats KNN for impedance (RMSE 1.27 vs 1.41 Ω), while **KNN beats CNN for localization (RMSE 1.34 cm vs 15.06 cm; MAE 5.0 mm vs 23 mm)**. A higher compression factor slightly improves localization in noisy conditions. No laboratory measurements were found in the text.
**Use in project.** This is the most directly comparable formulation to ours: single discontinuity, RG-58 coax, open/short/soft classes, Γ regression. *ML features/models:* use Γ (bounded in [−1, 1]) as the regression target and derive the class from it, and consider a two-stage detect→localize design. *Evaluation:* report RMSE/MAE/MAPE per fault class and stratified by SNR. *Model choice:* the evidence that a non-deep model (KNN) beats a CNN at localization supports using RF/Extra Trees. *Limitations/sim-to-real:* their results are simulation-only, which is exactly the gap our lab test set (E3) addresses.
**Sources checked:** Crossref API (bibliographic data and event; no abstract); Semantic Scholar API (abstract); OpenAlex API (abstract); HAL API `halId_s:cea-04741025` (abstract + keywords); HAL PDF `https://cea.hal.science/cea-04741025v1/file/Detection%20Localization%20and%20Characterization%20of%20fault.pdf` (full text read).

### 5. Slimani et al., IEEE I&M Magazine 2025: 10.1109/MIM.2025.11198883
**Summary (abstract).** This presents the same family of methods: machine learning combined with compressed acquisition of CHIRP-OMTDR. It emphasises that the approach fits directly into the measurement chain without signal reconstruction, cutting computational complexity, acquisition bandwidth and memory, which are key constraints in practical instruments. KNN and a CNN are compared for impedance estimation and localization, and the paper studies how the compression factor affects localization **and classification**. The authors report accurate detection, localization and characterization of cable faults. The abstract gives no cable type, dataset size, lab-vs-simulation split or numbers: **UNVERIFIED** (full text not read). It is probably an extended magazine version of paper 4, but that is not verified.
**Use in project.** Use it as a recent (2025) related-work citation showing that ML on reflectometry is being pushed into instrument hardware. In the discussion, use it to argue that compact inputs (256 resampled samples or about 15 engineered features) and lightweight tree models are sensible under acquisition and memory constraints. Cite it together with paper 4, and take numerical comparisons from paper 4, whose full text was verified.
**Sources checked:** Crossref API (bibliographic data; no abstract); Semantic Scholar API (abstract); OpenAlex API (abstract, identical); HAL API `halId_s:cea-05426836` (abstract + index keywords); HAL PDF `https://cea.hal.science/cea-05426836v1/...pdf` (**blocked by HAL's anti-robot page; full text NOT read**).
